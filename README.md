
# CodeSwitch Sentinel

**Track:** AI + Languages

## Overview
CodeSwitch Sentinel is a research project investigating whether machine learning can distinguish four types of multilingual text:

- English (EN)
- Bangla script (BN)
- Romanized Bangla (BN-ROM)
- Mixed Bangla-English (MIXED)

## Research Question
Can character-level machine learning reliably classify short messages across these four categories?

## Planned Technology
- Python
- Scikit-learn
- Character-level TF-IDF
- Logistic Regression
- Google Colab
- GitHub Pages

## Research Goals
1. Build a labeled dataset.
2. Train a classification model.
3. Compare it with a baseline.
4. Evaluate performance separately for each category.
5. Investigate classification errors.

## Current Status
Website interface created.
Machine-learning model not yet connected.

## Research Integrity
Results will be reported using actual experiments.
No unverified performance claims will be made.
